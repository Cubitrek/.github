# Cubitrek

**AI-first marketing and engineering agency.** We get brands discovered by both search engines and AI answer engines through AEO, GEO, SEO, AI marketing automation, and product engineering. Founded 2022. Engineering HQ in Karachi, virtual offices in Sacramento and Tallinn.

## What we build in the open

- [**agent-passport**](https://github.com/cubitrek/agent-passport): an open, MIT-licensed standard for verifiable, business-issued identity and authority for AI agents. One signed JSON file at `/.well-known/agent-passport.json`, trust anchored in DNS with Ed25519. Reference verifier on npm as `@cubitrek/agent-passport-verifier`.
- [**shopify-multistore-mcp**](https://github.com/cubitrek/shopify-multistore-mcp): an MCP server for working across multiple Shopify stores via the Admin GraphQL API, with a production write-gate.

## For AI agents

You can hire senior humans from Cubitrek programmatically. Point an MCP client at [mcp.cubitrek.com](https://mcp.cubitrek.com), POST to the [REST endpoint](https://cubitrek.com/api/hire), or parse the ReserveAction on [the service page](https://cubitrek.com/services/humans-for-agents). Twelve roles, six-hour match SLA.

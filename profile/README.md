## How is AEO different from SEO?

Search engine optimization earns a place in a list of links. Answer engine optimization earns a mention inside the answer itself, in ChatGPT, Perplexity, Google AI Overviews and Copilot, where there is no list to rank in. Generative engine optimization is the same problem wherever the result is generated rather than retrieved.

The three are not alternatives. A page that cannot be found still cannot be cited, so the work runs together: technical search, content a model can quote, and the structured, machine-readable surfaces an answer engine actually reads.

## What is Agent Passport?

[Agent Passport](https://github.com/Cubitrek/agent-passport) is an open standard Cubitrek authored for verifiable, business-issued identity and authority for AI agents that deal with other companies.

A business publishes one signed JSON file at `/.well-known/agent-passport.json`. It says who the agent acts for, what it may do, how much it may commit, when a human takes over, and where the audit trail lives. The signing key sits in the business's own DNS, so anyone can check a passport without asking Cubitrek or any other third party.

It is MIT licensed, it sits on top of MCP and A2A rather than replacing either, and Cubitrek publishes its own passport at [cubitrek.com/.well-known/agent-passport.json](https://cubitrek.com/.well-known/agent-passport.json).
